# hxn2vr

Форк [uHexen2](https://github.com/sezero/uhexen2) (движок Hexen II) с поддержкой 6DoF VR через OpenXR.

- Upstream: remote `upstream`, ветка `master` (https://github.com/sezero/uhexen2).
- Базовая ветка проекта: `master`. Рабочие ветки фаз, например `phase0-foundation`.
- Лицензия: GPLv2, см. `LICENSE`.

## Правила изменений

- VR-код лежит в `engine/vr` и принадлежит нам целиком.
- Правки в остальном коде движка помечаются комментарием `// HXVR` (однострочный) или `/* HXVR */` (блок), чтобы их было видно при слиянии с upstream.
- Посмотреть все наши правки в движке вне `engine/vr`:

  `git diff upstream/master -- engine ':!engine/vr'`

## Управление в VR

Запуск в шлеме: `scripts\play-vr.cmd` (нужна Release-сборка и подключённый OpenXR-рантайм, например Virtual Desktop или SteamVR). Лог: `build\game\debug_h2.log`.

Cvar'ы пишутся в консоли и на командной строке как `vr_x значение` / `+vr_x значение` (команды `set` в Hexen II нет). Все cvar'ы этапа 2 сохраняются в `config.cfg`, кроме `vr_mock_*`.

### Раскладка по умолчанию

Раскладку ставит команда `vr_bind_defaults`; при старте VR она выполняется сама, если ни одна VR-клавиша ещё не назначена. «Главная» рука задаётся `vr_mainhand` (по умолчанию правая). Привязать другое действие можно обычным `bind VR_TRIGGER "..."`; имена клавиш — `VR_*` из таблицы.

| Клавиша | Физически (правша, Touch) | Действие по умолчанию |
|---|---|---|
| `VR_TRIGGER` | правый курок | `+attack` (атака) |
| `VR_GRIP` | правый grip | `impulse 10` (следующее оружие) |
| `VR_A` | A | `+jump` (прыжок) |
| `VR_B` | B | `+crouch` (присед) |
| `VR_STICK` | клик правого стика | `vr_recenter` |
| `VR_OTRIGGER` | левый курок | `invuse` (использовать предмет) |
| `VR_OGRIP` | левый grip | `+showinfo` (информация) |
| `VR_X` | X | `invleft` (инвентарь влево) |
| `VR_Y` | Y | `invright` (инвентарь вправо) |
| `VR_OSTICK` | клик левого стика | `+speed` |
| Menu | левая кнопка ≡ (Index: левая B) | всегда Escape, не переназначается |

Стики:
- второй (не главной) руки — движение; по умолчанию относительно направления этой руки (`vr_movement_mode 1`), а если поза руки недоступна — относительно головы;
- главной руки — поворот: snap на `vr_snap_angle` градусов (по умолчанию) или плавный (`vr_turn_mode 1`).

Тело двигается и от реальных шагов в комнате (room-scale), а физическое приседание включает игровой присед.

### Меню, консоль и диалоги

- Menu открывает меню и работает как Escape.
- Пока открыты меню или консоль, любой стик даёт стрелки (с автоповтором); курок главной руки, A и X — Enter; B, Y и Menu — Escape (назад). В меню назначения клавиш приходят «сырые» коды `VR_*`, а Menu отменяет назначение.
- В диалогах «да/нет» (например, выход из игры): курок главной руки, A и X — «да»; B, Y и Menu — «нет».
- Выход из игры с контроллера: Menu → Quit → A.

### Настройки (cvar'ы)

Управление:

| cvar | По умолчанию | Смысл |
|---|---|---|
| `vr_mainhand` | 1 | главная рука: 0 левая, 1 правая |
| `vr_movement_mode` | 1 | движение: 0 — по голове, 1 — по направлению второй руки |
| `vr_turn_mode` | 0 | поворот: 0 snap, 1 плавный |
| `vr_snap_angle` | 45 | угол snap-поворота, градусы |
| `vr_turn_speed` | 150 | скорость плавного поворота, градусы/с |
| `vr_stick_deadzone` | 0.15 | радиальная мёртвая зона стиков |

Тело, рост и комфорт:

| cvar | По умолчанию | Смысл |
|---|---|---|
| `vr_roomscale` | 1 | room-scale: тело следует за реальными шагами |
| `vr_roomscale_radius` | 0.25 | м: насколько голова может уйти от центра тела, прежде чем пойдёт тело |
| `vr_crouch_physical` | 1 | физическое приседание включает игровой присед |
| `vr_crouch_threshold` | 0.65 | доля `vr_eye_height`, ниже которой считается приседом (выход из приседа — на 0.05 выше) |
| `vr_seated` | 0 | режим сидя: физическое приседание выключено, высоту задаёт `vr_height_offset` |
| `vr_height_offset` | 0 | м: прибавляется к высоте головы и рук (выставляет `vr_calibrate` в режиме сидя) |
| `vr_body_arm_length` | 0 | м: длина руки, 0 — по пропорциям тела |
| `vr_body_shoulder_width` | 0 | м: ширина плеч, 0 — по пропорциям тела |
| `vr_head_collision` | 1 | голова не проходит сквозь потолок; затемнение, когда голова в стене |
| `vr_vignette` | 1 | виньетка при движении стиком и плавном повороте |
| `vr_vignette_strength` | 0.6 | сила виньетки, 0..1 |

Масштаб, рост и панель (с этапа 1):

| cvar | По умолчанию | Смысл |
|---|---|---|
| `vr_world_scale` | 1.2 | масштаб мира: больше — мир «меньше» относительно вас |
| `vr_eye_height` | 1.65 | м: высота глаз стоя (ставит `vr_calibrate`) |
| `vr_panel_pitch` | 15 | градусы вниз от уровня глаз: наклон панели меню и HUD |
| `vr_panel_distance` | 1.5 | м: расстояние до панели |
| `vr_panel_width` | 1.2 | м: ширина панели |

### Команды

- `vr_calibrate` — калибровка роста и длины руки. Стоя: выпрямитесь, смотрите вперёд и нажмите курок главной руки; затем вытяните главную руку вперёд на уровне плеч и снова нажмите курок. В режиме сидя (`vr_seated 1`) на первом шаге сядьте удобно: рост не меняется, а высоту голове добавляет `vr_height_offset`. Отмена: `vr_calibrate cancel`, курок второй руки, B или Y. Нереалистичные значения (рост или рука вне диапазона) отклоняются с сообщением; прежние значения остаются.
- `vr_body` — печатает размеры модели тела в метрах (рост, плечи, рука, высота приседа, смещение).
- `vr_bind_defaults` — вернуть раскладку по умолчанию.
- `vr_recenter` — поставить камеру над телом (также клик правого стика).
- `vr_status` — состояние VR: бэкенд, рантайм, размер глаза, частоты кадров и тиков, профили и состояние обеих рук.

Для разработчиков: `vr_where` печатает положение тела, наклон, высоту вида и число удержанных VR-кнопок; `vr_mock_hand` и `vr_mock_head` задают позы и кнопки для mock-бэкенда (`+vr_backend mock`), на них построен `tests/smoke/vr-mock-smoke.ps1`.

### Известные ограничения этапа 2

- Прицеливание и стрельба по-прежнему от головы; от руки — этап 3.
- Модели оружия на руке нет.
- HUD остаётся на панели.
